# 本地部署与启动

本文记录 `sciencefl.github.io` 项目在本地的安装、启动和构建方式。

## 项目说明

- 技术栈：`VuePress 2` + `vuepress-theme-hope`
- 包管理器：`pnpm@10.33.2`
- Node.js：建议使用 `Node.js 20`

## 1. 进入项目目录

```bash
cd /Users/felix/Development/source_code/git_person/sciencefl.github.io
```

如果你已经在项目根目录，可以跳过这一步。

## 2. 安装依赖

首次启动前，需要先安装依赖：

```bash
corepack enable
pnpm install
```

说明：

- `corepack enable` 用来启用 `pnpm`
- 项目已经在 `package.json` 中固定了 `pnpm@10.33.2`
- 不建议直接复用其他机器或其他系统拷贝过来的 `node_modules`

## 3. 启动本地开发服务

执行：

```bash
pnpm docs:dev
```

默认情况下，VuePress 会监听：

```text
http://localhost:8080
```

浏览器打开后即可本地预览站点。

## 4. 指定本地监听地址或端口

如果你只想监听本机地址，或者需要换一个端口，可以执行：

```bash
pnpm docs:dev -- --host 127.0.0.1 --port 8081
```

此时访问地址为：

```text
http://127.0.0.1:8081
```

## 5. 构建静态站点

如果你想验证生产构建是否正常，执行：

```bash
pnpm docs:build
```

构建完成后，静态文件输出到：

```text
docs/.vuepress/dist
```

## 6. 本地预览构建产物

可以用一个简单的静态文件服务器预览构建结果，例如：

```bash
python3 -m http.server 4173 -d docs/.vuepress/dist
```

然后访问：

```text
http://localhost:4173
```

## 7. 常见问题

### 依赖无法使用或构建报平台错误

如果出现类似 `esbuild` 平台不匹配、`vuepress-webpack` 无法执行之类的问题，通常说明当前 `node_modules` 来自错误平台，建议直接重装：

```bash
rm -rf node_modules
pnpm install
```

### 8080 端口被占用

如果默认端口被占用，直接换端口启动：

```bash
pnpm docs:dev -- --port 8081
```

### 构建成功但页面没有更新

可以清理缓存后重新启动：

```bash
pnpm docs:clean-dev
```

## 常用命令汇总

```bash
pnpm install
pnpm docs:dev
pnpm docs:dev -- --host 127.0.0.1 --port 8081
pnpm docs:build
pnpm docs:clean-dev
python3 -m http.server 4173 -d docs/.vuepress/dist
```

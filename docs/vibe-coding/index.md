# Vibe Coding

Vibe Coding 不是放弃工程约束，而是把自然语言、代码代理和验证工具组织成一条可复盘的开发流程。

## 学习路线

1. 先把想法整理成边界清晰的任务。
2. 再让 AI 参与探索、实现和重构。
3. 用测试、构建、审查和运行结果把直觉变成证据。

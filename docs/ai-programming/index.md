# AI 编程与原理

本专题关注 AI 编程背后的机制，以及这些机制如何影响开发效率、代码质量和工程边界。

## 学习路线

1. 理解模型如何处理 Token、上下文和指令。
2. 理解 Prompt、工具调用、Agent 和评估之间的关系。
3. 将原理映射到真实的编码、调试和知识管理工作流。

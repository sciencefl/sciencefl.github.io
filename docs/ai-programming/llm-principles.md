# LLM 基础原理

大语言模型可以理解为根据已有上下文预测后续 Token 的参数化模型。这个描述并不等于模型只能续写文本，但它揭示了上下文、概率和采样在交互中的基础作用。

## 从输入到输出

```mermaid
flowchart LR
  A[指令与上下文] --> B[Token 化]
  B --> C[模型计算]
  C --> D[概率分布]
  D --> E[采样或选择]
  E --> F[输出 Token]
  F --> C
```

## 对编程的影响

- 上下文越清晰，模型越容易保持目标一致。
- 代码库结构和约束需要被显式提供或稳定地检索。
- 输出需要通过测试、审查和运行结果验证，而不能只看语言流畅度。

因此，AI 编程的核心不只是生成代码，还包括上下文设计和结果验证。
